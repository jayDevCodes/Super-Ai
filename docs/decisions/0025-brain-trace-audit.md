# ADR 0025: Brain Trace Correlation in Audit Events

## Status

Accepted.

## Decision

Every Brain plan/execution receives an immutable trace context. The trace ID and span ID are added to Brain audit events so planning, execution start/finish, and per-step events can be correlated.

OpenTelemetry defines TraceId and SpanId as the core identifiers of execution context and recommends recording trace context alongside logs/events for correlation. W3C Trace Context standardizes propagation of these identifiers across component boundaries. citeturn932278search1turn932278search11

Super-Ai keeps this dependency-free for now and uses its local `TraceContext` primitive.

## Consequences

Audit analysis can group all events generated by a single Brain invocation without recording task prompts or untrusted execution output.
